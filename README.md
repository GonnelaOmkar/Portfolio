# Omkar Gonnela — Portfolio Website 🚀

A modern, interactive 3D portfolio website showcasing my projects, skills, and education background. Built with React, TypeScript, Three.js, and GSAP for smooth animations and an immersive user experience.

🔗 **Live:** (https://omkargonnela.omkargonnela.workers.dev/)

---

## ✨ Features

- **Interactive 3D Character** — Animated WebGL character model rendered with Three.js & React Three Fiber
- **Physics-based Tech Stack** — Floating 3D spheres with Rapier physics engine showcasing my technologies
- **Smooth Scroll Animations** — Powered by GSAP ScrollSmoother & ScrollTrigger
- **Horizontally Scrolling Projects** — Showcase section with GSAP-driven horizontal scroll
- **Custom Cursor** — Interactive cursor effects for a premium feel
- **Fully Responsive** — Optimized for desktop and mobile devices

## 📂 Projects Featured

### 1. Hybrid Multi-Domain Recommendation System
> Python · FastAPI · Google Gemini API · scikit-learn · MongoDB · Parquet

A hybrid recommendation engine for movies, books, and music combining content-based filtering (text embeddings + cosine similarity) with collaborative filtering (SVD matrix factorization). Integrated Gemini API for natural-language explanations.

### 2. SafeStreet — Road Damage Detection & Alert System
> Python · PyTorch · YOLOv5 · OpenCV

Trained a YOLOv5 object detection model to detect and classify road defects with severity tiers. Built a mobile app for GHMC field workers and a severity-sorted dashboard with map visualization.

### 3. CineSearch — Movie Discovery App
> React · React Router · TMDb API · Axios · Vercel

A responsive movie discovery web app with live search (debounced), genre-based filtering, sorting by rating, and a persistent watchlist using localStorage. Deployed on Vercel with CI/CD.

## 🛠️ Getting Started

```bash
# Clone the repository
git clone https://github.com/GonnelaOmkar/Portfolio.git

# Navigate into the project
cd Portfolio

# Install dependencies
npm install

# Start the development server
npm run dev
```

The app will be available at `http://localhost:5173/`
